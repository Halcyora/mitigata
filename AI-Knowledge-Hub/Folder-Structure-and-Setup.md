## Local setup

The workspace is ready to use as-is. No remote sync, Confluence upload, or SharePoint setup is needed for the hackathon prototype.

1. Open this folder in VS Code.
2. Start from [Getting-Started-From-Scratch-VSCode-Copilot.md](../Getting-Started-From-Scratch-VSCode-Copilot.md).
3. Read [docs/PS5-SAST-DAST-Correlation-Engine.md](../docs/PS5-SAST-DAST-Correlation-Engine.md) before writing any code.
4. Create your prototype repo separately and copy the templates from `ai-dlc-generic-repository-templates/`.
